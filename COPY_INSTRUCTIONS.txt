PHASE 17B — Flat Percentage Modifier Pricing Fix

PURPOSE
Fix percentage-based extras/modifiers so they are always calculated from the
same base service price instead of compounding on top of previously selected extras.

BEFORE
Base $100
+20% playlist => $120
+45% Play With Booster calculated from $120
+20% Express calculated from the already modified amount

This caused compounded/exponential price growth.

AFTER
Base $100
+20% playlist = +$20
+45% Play With Booster = +$45
+20% Express = +$20

Every percentage is calculated from the SAME base service price.

ROCKET LEAGUE SERVICES FIXED
- Rank Boost
- Competitive Wins
- Placements Boost
- Rewards Boost
- Tournament Boost

GENERIC PRICING ENGINE
- Mock percentage modifiers are now additive percentages.
- Database option_multiplier / boolean_multiplier rules are now combined additively
  against the same calculated service base instead of multiplied together.

IMPORTANT PRICING BEHAVIOR
- Rank progression/package price remains unchanged.
- Existing volume/package discounts remain unchanged.
- For Wins / Placements / Rewards, the discounted core service price is the percentage base.
- Fixed-price extras such as Live Stream +$10 remain fixed-price.
- Appear Offline remains $0.
- Existing orders and stored price snapshots are not recalculated.
- New quotes/orders use the corrected behavior.

RULE SET VERSION
Rocket League service-specific pricing versions were bumped from v1.0 to v1.1
so new order snapshots reflect the pricing-engine correction.
