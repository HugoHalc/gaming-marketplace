# MVP Scope

## Goal

Validate that customers can discover a gaming service, configure it, receive a trustworthy price, pay, and understand the order state.

## Include

1. Premium marketing homepage
2. Data-driven games catalog
3. Game detail page
4. Service detail and configuration flow
5. Server-authoritative dynamic pricing
6. Supabase-backed catalog and pricing configuration
7. Customer registration and login
8. Order creation
9. Stripe payment flow
10. Customer order list and order detail
11. Minimal customer profile
12. Admin management for games, services, pricing, and orders
13. Basic promotion support
14. Production security, SEO, monitoring, and deployment

## Defer

- realtime chat
- complex review/reputation system
- affiliate program
- loyalty points
- multiple vendors or seller marketplace logic
- advanced staff permissions
- automated booster assignment
- multi-currency settlement
- native mobile applications
- complex recommendation engines
- deep personalization

## MVP success criteria

- A new game/service can be published from data without a frontend code change.
- Pricing cannot be manipulated by editing browser requests.
- A successful Stripe payment produces a traceable paid order.
- A customer can see the current state and history of their own orders.
- An admin can manage the core commercial catalog without database-level manual work.
- The application is usable and fast on modern mobile and desktop devices.
