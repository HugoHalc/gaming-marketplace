# Phase 12F — Rank Showcase UI

This phase moves the Rocket League Rank Boost rank selector much closer to the
approved visual mockup while keeping BoostingPedia's own visual identity.

## Design direction

Inspired by the efficiency and premium hierarchy of leading gaming boosting
marketplaces, without copying their layout or artwork.

## Changes

- Horizontal rank badge strip for fast rank-family selection.
- Premium large selected-rank badge under each strip.
- Strong Current Rank → Target Rank visual relationship.
- Center progression arrow on desktop.
- Rank name displayed as a high-impact showcase element.
- Tier I / II / III controls integrated into each rank showcase.
- Supersonic Legend receives its own final-rank treatment.
- Current Rank still stops at Grand Champion III.
- Target Rank still supports Supersonic Legend.
- Original BoostingPedia custom rank art remains in use.

## Brand identity

- Black remains the primary canvas.
- BoostingPedia green is used for interaction, selection, trust and conversion.
- Rank-specific colors remain visible rather than forcing every rank to green.
- The result is intended to feel like a dedicated gaming product, not a generic form.

## Unchanged

Pricing, order flow, Stripe, Supabase, dashboard, admin and notifications.
