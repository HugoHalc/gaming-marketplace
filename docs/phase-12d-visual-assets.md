# Phase 12D — Rocket League Visual Assets

This pass adds the missing visual asset layer to the Rocket League Rank Boost
configurator.

## Included

- Original custom rank badge art for:
  - Bronze
  - Silver
  - Gold
  - Platinum
  - Diamond
  - Champion
  - Grand Champion
  - Supersonic Legend
- Colored platform logos/icons for:
  - PC / Steam
  - PlayStation
  - Xbox
  - Nintendo Switch
- Rank selector cards now use custom badge images instead of text initials.
- Platform selector now uses branded icons and color accents.

## Important

The rank badge artwork is custom/original and does not use the official Rocket
League rank images.

## Unchanged

- Pricing
- Rank logic
- Supabase
- Orders
- Stripe
- Dashboard/Admin
