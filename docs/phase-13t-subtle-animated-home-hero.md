# Phase 13T — Subtle Animated Home Hero

Adds restrained motion to the approved Phase 13S hero.

## Motion
- 10-second slow float, only 7 px horizontally / 5 px vertically.
- Very subtle brightness and saturation breathing.
- Soft green environmental glow pulse behind the artwork.
- No rotation.
- No aggressive zoom.
- No flashy neon or noisy particle system.
- No layout shift.

## Accessibility
Animation is disabled automatically for users with `prefers-reduced-motion: reduce`.

## Unchanged
- hero artwork asset
- hero layout
- hero copy
- buttons
- navigation
- all other sections
- game cards
- functionality
