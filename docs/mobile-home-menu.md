# Mobile Home Menu

Adds a real mobile navigation trigger to the public SiteHeader.

Behavior:
- hamburger visible below lg breakpoint
- full-height right-side mobile drawer
- body scroll locked while open
- closes with X, overlay, Escape, or navigation
- safe-area padding for iPhone
- public links use real existing routes/anchors
- signed-out state: Sign up + Sign in
- signed-in state: Dashboard + Orders + Account Settings + Log out
- desktop navigation remains unchanged

Visual direction is inspired by the provided reference structure only; colors and styling remain BoostingPedia.
