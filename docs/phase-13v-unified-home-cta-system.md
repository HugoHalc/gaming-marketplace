# Phase 13V — Unified Home CTA System

Applies a consistent visual system to Home page buttons, action links and compact controls only.

## Primary
- Background `#39E56F`
- Text `#050807`
- Hover `#20C95A`
- 12px radius
- 600 weight
- Restrained green shadow

## Secondary
- Background `#131B17`
- Border `#FFFFFF14`
- Text `#F4F7F5`
- 12px radius
- Hover surface slightly lighter
- Hover border green at ~30%
- No glow

## Tertiary
- Transparent
- Text `#A0AAA4`
- Hover `#82F5A4`
- No box or glow

## Circular controls
- Background `#090D0B`
- Border `#FFFFFF14`
- Icon `#A0AAA4`
- Hover background green ~9%
- Hover border green ~35%
- Hover icon `#82F5A4`

## States
- Active: translucent green background + green border
- Disabled: reduced opacity and no elevated visual treatment

No structure, copy, layout, navigation or functionality changed.
