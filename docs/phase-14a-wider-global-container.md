# Phase 14A — Wider Global Container

Widens the global content canvas without changing the page structure.

## Change
- Global max width:
  - from `max-w-7xl` (~1280 px)
  - to `max-w-[1520px]`
- Keeps centered alignment.
- Preserves existing mobile/tablet padding.
- Adds slightly more breathing room on very large screens with `2xl:px-10`.

## Expected effect
- Less excessive empty space on wide monitors.
- Header spans feel more intentional.
- Hero text/artwork balance improves.
- Boosters and game sections use more horizontal space.
- Layout remains centered and controlled instead of becoming full-width.

## Unchanged
- typography
- component sizes
- hero dimensions
- card dimensions
- copy
- navigation
- functionality
- section structure
