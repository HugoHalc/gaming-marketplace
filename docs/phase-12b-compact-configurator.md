# Phase 12B — Compact Rocket League Configurator UX

This update changes presentation only.

## Goals

- Reduce vertical scrolling.
- Put Current Rank and Desired Rank side by side on desktop.
- Use smaller rank cards while preserving visual rank identity.
- Hide unavailable lower target rank families instead of showing locked cards.
- Keep 1v1, 2v2 and 3v3 immediately visible.
- Show two Extra Modes first, with an expandable list for the rest.
- Keep platform selection compact.
- Reduce Boost Method card height.
- Present optional upgrades as compact rows.
- Keep the order summary sticky on wide screens.

## Unchanged

- Rocket League pricing.
- Tier-step matrix.
- Package ceilings.
- Playlist multipliers.
- Play With Booster +45%.
- Live Stream +$10.
- Express Delivery +20%.
- Rank Insurance +50%.
- Server-authoritative quote calculation.
- Order, Stripe, dashboard, admin and notification flows.

No Supabase migration is required.
