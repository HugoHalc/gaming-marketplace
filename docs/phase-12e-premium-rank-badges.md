# Phase 12E — Premium Rank Badges

This phase upgrades the Rocket League rank badge artwork to feel more premium
and closer to the high-end visual style approved for BoostingPedia.

## Improvements

- Replaced the previous simplified rank icons with more premium original badge art.
- Added:
  - metallic outer frames,
  - richer gradients,
  - inner panel depth,
  - more detailed silhouettes,
  - glow and highlight treatment,
  - stronger visual presence in the selector.
- Slightly increased badge size in the configurator.
- Preserved the compact layout and all existing pricing/order logic.

## Notes

The badge art is original/custom and is not copied from the official Rocket League rank assets.

## Unchanged

- Rank structure
- Current Rank limit
- Target Rank availability
- Pricing
- Order flow
- Stripe
- Supabase
