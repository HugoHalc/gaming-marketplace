# Phase 13E — Geist + Rajdhani Typography System

## Primary typography
Geist remains the default font for:
- body copy
- paragraphs
- navigation
- buttons
- forms
- long descriptions
- general UI text

## Secondary gaming typography
Rajdhani is loaded only in weights 600 and 700.

### `.font-gaming-label`
Rajdhani SemiBold 600 for:
- labels
- categories
- badges
- small competitive headings
- short metadata

### `.font-gaming-value`
Rajdhani Bold 700 for:
- ranks
- highlighted numbers
- important prices
- short gaming/service titles

## Important
No font size, line height, layout, spacing, structure, or content changes are included.

The system is intentionally restrained to preserve BoostingPedia's premium visual direction.
