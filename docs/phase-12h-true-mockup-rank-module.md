# Phase 12H — True Mockup Rank Module

This phase rebuilds the Rocket League rank module to closely match the approved
BoostingPedia mockup direction.

## Main changes

- Mini rank strip at the top of Current and Desired Rank.
- Rank family names beneath each mini badge.
- Selected rank receives an underline/glow treatment.
- Large selected-rank hero artwork.
- Large, untruncated rank title.
- Tier controls integrated beside the hero badge.
- Current and Desired panels presented as one composed module.
- Central progression arrow on desktop.
- Rank-specific color glow around each hero badge.
- Supersonic Legend gets a special final-rank state.
- Supporting rank guidance appears inside each showcase panel.

## Preserved

- Current Rank stops at Grand Champion III.
- Desired Rank can reach Supersonic Legend.
- Server-authoritative pricing.
- Existing playlist/platform/method/extras logic.
- Stripe, Supabase, orders, dashboard and admin flow.
