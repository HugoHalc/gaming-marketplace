# Phase 14X — Final CTA Brand Polish

Scope is intentionally limited to the final CTA on the Home page.

## Visual direction
- Keeps the existing horizontal desktop composition.
- Keeps the same headline, supporting copy and primary CTA.
- Uses an extremely subtle #090D0B → #0E1411 surface gradient.
- Preserves the soft green ambient glow, slightly reduced.
- Adds low-opacity angular geometry inspired by the BoostingPedia mark language.
- Adds one tiny neutral node and one restrained micro-label.
- No giant logo, no game art, no 3D, no glassmorphism and no bright border treatment.

## Label
- BoostingPedia pill is now neutral.
- #FFFFFF14 border.
- #0E1411 surface.
- #A0AAA4 label/icon.

## CTA
- `Browse games` remains the only high-contrast chromatic element.
- #39E56F default.
- #20C95A hover.
- 12px radius.
- Very controlled shadow.
- No movement/elevation of the overall CTA block.
- Full width on the smallest breakpoint, auto width from sm upward.

## Responsive
- Decorative angular geometry is hidden below lg.
- Micro-label is hidden on the smallest screens.
- No unrelated sections changed.
