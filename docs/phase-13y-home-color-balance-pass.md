# Phase 13Y — Home Color Balance Pass

Global visual color-balance pass for the Home page only.

## Goal
Approximate visual balance:
- 80–85% black / gray / white
- 15–20% green / cyan

## Key changes
- Section eyebrow labels become neutral gray.
- Hero keeps its green artwork/glow and primary CTA, while trust bullets become neutral.
- Boosters keeps green for online status only; metadata, rating, controls and hover become more neutral.
- How it Works keeps green in the large step numeration, while connectors, nodes, icons and hover become neutral.
- Marketplace Foundation receives the strongest reduction:
  - most icons and telemetry details become gray/white
  - only SYS-02 and SYS-05 retain restrained green accents
  - hover is neutral instead of green
- Final CTA block becomes mostly neutral with one green primary action.
- Game cards are intentionally left unchanged because each title has its own color identity.
- Cyan remains only as a small hero detail.

## Unchanged
- structure
- layout
- copy
- typography
- sizes
- components
- images
- hierarchy
- functionality
- navigation
