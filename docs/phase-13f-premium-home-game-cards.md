# Phase 13F — Premium Home Game Cards

Scope is intentionally limited to the 7 game cards on the Home page.

## Shared card system
- Dark BoostingPedia surface
- Subtle game-specific accent gradient
- Game/category label at upper left
- Large low-opacity game-name watermark
- One strong local visual asset on the right
- Circular arrow CTA at lower left
- Subtle border and radius
- Restrained hover
- No excessive glow or saturation

## Accent colors
- Rocket League: #3DA9FC
- League of Legends: #C89B3C
- Valorant: #FF5A6B
- Marvel Rivals: #EF4444
- Overwatch: #F97316
- Battlefield 6: #60A5FA
- Rainbow Six Siege: #94A3B8

## Image assets
The repository did not contain existing final key art for these games.
This phase therefore uses lightweight local SVG placeholder artwork:
`public/game-cards/*.svg`

These assets are deliberately easy to replace later with final artwork without changing the card layout.

No global layout, UX, sections, game availability, Rocket League logic, pricing, or configurators are modified.
