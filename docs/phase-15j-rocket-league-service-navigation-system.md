# Phase 15J — Rocket League Service Navigation System

Adds a shared service navigation layer to the five Rocket League configurators.

Desktop:
- sticky left sidebar
- active service highlighted with contextual Rocket League blue
- small BoostingPedia green active indicator
- compact numbered service markers
- direct link back to Rocket League overview

Mobile / tablet:
- horizontal scrollable service navigation
- active route remains visible
- scrollbar hidden
- no vertical sidebar

Existing routes:
- `/games/rocket-league/rank-boost`
- `/games/rocket-league/wins`
- `/games/rocket-league/tournament-boost`
- `/games/rocket-league/rewards-boost`
- `/games/rocket-league/placements-boost`

No configurator components, pricing, APIs, checkout, Order Summary logic, header, footer, or hero structure are changed.
