# Phase 14Z — Marketplace Foundation Polish

Scope is intentionally limited to the Marketplace Foundation section on Home.

## Copy direction
Reframes the section from internal-system language to customer-facing confidence.

- Eyebrow: `Built for confidence`
- Headline: `A marketplace designed around the details that matter.`
- Supporting copy:
  `From secure account flows to clear pricing and order progress, every part of BoostingPedia is built to make the experience easier to understand and manage.`

## Visual cleanup
Removed:
- SYS-01 through SYS-06
- `Foundation` status labels
- `Active module`
- active/inactive-looking status dots
- excessive technical line decoration
- card lift on hover

Preserved:
- six benefits
- 3×2 desktop grid
- dark premium surfaces
- small icons
- subtle dividers

## New card language
Each benefit card now uses:
- compact icon block
- benefit title
- concise description
- restrained footer metadata: `Built into every order`

Only two cards receive a controlled green icon accent. The rest remain neutral.

No other Home section, route, data flow, or feature is changed.
